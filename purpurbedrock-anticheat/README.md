# PurpurBedrockAC `26.2` — Адаптивный античит под ядро Purpurbedrock

**`PurpurBedrockAC-26.2.jar`** — отдельный высокооптимизированный античит-плагин, написанный специально под ядро **`Purpurbedrock 26.2`** (`Bedrock 1.21.0 — 26.52`). Находится в изолированном модуле `purpurbedrock-anticheat/` и никак не вмешивается в код самого ядра.

## Установка

Положите готовый файл **`PurpurBedrockAC-26.2.jar`** (из релиза [`v26.2.0-bedrock`](https://github.com/gulp-tech/Purpurbedrock/releases/tag/v26.2.0-bedrock)) в папку `plugins/` вашего сервера и перезапустите сервер. Конфиг создастся в `plugins/PurpurBedrockAC/config.yml`.

## Ключевые особенности

1. **Адаптивный «Спящий» режим (`DORMANT` → `SLEEPING` → `WAKING` → `AWAKE`)**
   - Когда на сервере тихо или игроки играют честно — античит буквально **спит** (`0% CPU`, редкий фоновый пульс `1/4` без аллокаций памяти).
   - При первых странных действиях у конкретного игрока античит **плавно и не спеша просыпается** (`suspicionHeat`) **только для этого игрока**, включая глубокую 3D-геометрию хитбоксов и трассировку, а затем снова засыпает, когда всё чисто.
   - При просадке TPS ниже `18.0` строгие проверки автоматически замирают, чтобы никогда не выдавать ложные флаги.

2. **Калибровка специально под физику Bedrock (`Purpurbedrock 26.2`) — без ложных срабатываний**
   - Напрямую считывает из ядра реальный **режим управления** (`Сенсор`, `Клавиатура+Мышь`, `Контроллер`), **устройство** (`📱 Телефон`, `🖥 ПК`, консоли), **версию клиента** и **реальный RakNet/NetherNet RTT пинг**.
   - Раздельные лимиты `Reach`, `HitBox` и `AutoClicker` для **Сенсора** (где можно тапать в край экрана без наведения прицела!) и для **ПК / Контроллера**.
   - Не трогает легитный **спид-бриджинг Bedrock** и свешивание на `0.5` блока, лестницы, полублоки, лёд, слизь, элитры, трезубцы и взрывное откидывание.

3. **Защита от популярных читов (`Horion`, `Toolbox`, `Prax`, `PacketClient`, `Zephyr`, `Apollo`, автокликеры)**
   - **Боевые проверки**: `Reach` (3D AABB + 14-слотовая компенсация пинга), `HitBox`, `KillAura` (`MultiAura`, удары спиной `360°`, удары сквозь стены, удары с открытым GUI-меню), `AutoClicker` (лимит CPS + детектор ровных макросов по `stdDev`), `Velocity` (`AntiKB`).
   - **Проверки движения и мира**: `Fly` (`Hover` / `Jetpack Ascend` / `Glide`), `AirJump` (прыжки от пустого воздуха), `Speed / BHop`, `Timer`, `Jesus` (`WaterWalk`), `NoSlow`, `Scaffold` (постановка блоков в пустой воздух / сверх-дистанция), `BadPackets`.

4. **Небольшая голограмма `AVG` над игроками по праву (`purpurac.hologram`)**
   - Включается/выключается командой **`/pac holo`** (или прямо кнопкой в меню!).
   - Реализована на пакетно-изолированном `TextDisplay` без хитбокса (`setVisibleByDefault(false)` + `setPersistent(false)`):
     - Её видят **только модераторы**, включившие `/pac holo` (обычные игроки не видят вообще);
     - Не мешает ударам в PvP на Bedrock и не сохраняется в чанках мира;
     - Если ни у одного модератора голограмма не включена — **в мире 0 сущностей и 0 задач!**

5. **Меню истории игрока в стиле HolyWorld (`/pac menu`, `/pac history <ник>`)**
   - Сундучное `9x6` (`54` слота) меню, полностью совместимое с Bedrock:
     - 🟢 **Зелёные блоки** — чистые срезы игры / безопасные моменты;
     - 🟠 **Оранжевые блоки** — подозрительная активность на грани нормы;
     - 🔴 **Красные блоки** — подтверждённые срабатывания на читы / высокий риск;
     - **Внизу меню (слоты `46`, `47`, `48`)** расположены **три цветных блока-инструкции** (подсказки модератору по зелёному, оранжевому и красному уровням) + быстрые кнопки переключения голограммы `AVG`, алертов, телепорта к игроку и очистки `VL`.

## Права и команды

| Команда | Право | Описание |
|---|---|---|
| `/pac alerts` | `purpurac.alerts` | Включить / выключить алерты античита в чате |
| `/pac holo` (`/pac avg`) | `purpurac.hologram` | Включить / выключить небольшую голограмму `AVG` над игроками |
| `/pac menu` | `purpurac.menu` | Открыть общий мониторинг игроков (отсортирован по риску 🔴 → 🟠 → 🟢) |
| `/pac history <ник>` | `purpurac.menu` | Открыть меню истории игрока в стиле HolyWorld с инструкциями внизу |
| `/pac info <ник>` | `purpurac.menu` | Краткое досье игрока в чат |
| `/pac status` | `purpurac.alerts` | Статус адаптивного спящего движка, нагрузка в `мкс` и TPS |
| `/pac reset <ник>` | `purpurac.admin` | Очистить `VL`, `AVG` и историю игрока |
| `/pac reload` | `purpurac.admin` | Горячая перезагрузка `config.yml` без рестарта сервера |
