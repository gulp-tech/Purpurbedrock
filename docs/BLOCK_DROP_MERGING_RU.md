# Объединение выпавших блоков

При обычной обработке выпавших предметов ядро использует для предметов-блоков расширенную область поиска: по умолчанию 3 блока по горизонтали. Это не телепортация или магнит: совместимые сущности постепенно объединяются стандартным механизмом игры, с обычным ограничением размера стака, проверками данных и событием `ItemMergeEvent`. Несколько полных стаков останутся несколькими сущностями. Другие виды предметов используют обычную настройку Spigot.

Настройка для каждого мира в `purpur.yml`:

```yaml
world-settings:
  default:
    gameplay-mechanics:
      item:
        block-drop-merge-radius: 3.0
```

Это минимальный радиус для выпавших блоков; если `merge-radius.item` в `spigot.yml` больше, используется он. Значение 0 или отрицательное оставляет обычный радиус Spigot для блоков. Расширение не включается, если `merge-radius.item` не положителен. Значения больше 8 ограничиваются до 8; неконечные значения отключают расширение. Существующие `spigot.yml` и `purpur.yml` не переписываются вручную этой доработкой.

Поиск использует штатную прямоугольную область, не гарантирует строго ближайший предмет или мгновенное слияние. Расширение может объединять предметы дальше друг от друга, в том числе по разным сторонам границы привата: проверьте плагины защиты и их обработку `ItemMergeEvent`. При расширенном поиске проверяется наличие преград; настройка Paper `fix-items-merging-through-walls` и настройка только горизонтального объединения также продолжают действовать. Перед применением на основном сервере проверить взрывы, разные данные предметов, полные стаки, подбор, воронки и отмену события плагинами на тестовой копии.
