# Проверки сохранности предметов

Статус на момент проверки: это ограниченный набор автоматических проверок, а не доказательство отсутствия всех дюпов. Продуктивный сервер и его миры не изменяются.

## Что запущено

Workflow `.github/workflows/test-inventory-regression.yml` запускает отдельный сервер Purpurbedrock в GitHub Actions, временный плоский мир, тестовый Bukkit-плагин из `scripts/tests/inventory-fixture` и синтетические Bedrock-клиенты версии 26.51. Fixture не включается в боевое ядро. Используется отдельный успешный artifact сборки `43067647804` (commit `1e6a6a207a65ab9ab83faaf693d8c8af64274422`, тестовое ядро переходов меню). Проверки для текущего набора успешно выполнились в run `43184471792`.

## Проверенные инварианты

- Переключение встроенного меню, переходы тестового меню 27 → 54 → 9 слотов и возвращение к инвентарю; после отменённых кликов тестовые кнопки не оказались в инвентаре, курсоре или на земле.
- Перенос 20 помеченных PDC предметов из виртуального контейнера через курсор в инвентарь, повтор операции с устаревшим ID и закрытие окна: серверный суммарный счёт оставался 30.
- Отключение и повторное подключение при предметах на курсоре: серверный суммарный счёт остался 30, курсор очистился.
- Одновременная попытка двух клиентов взять один и тот же стек из общего виртуального контейнера: серверный суммарный счёт остался 30.
- Слияние выпавших блоков: количество, частичные стаки, разный PDC, твёрдая преграда и отмена `ItemMergeEvent`; обычные неблочные предметы за пределами штатного радиуса не сливались. Тест проверяет данные на сервере, не отрисовку клиента.

## Не проверено

- Настоящий интерфейс и управление клиента 26.60, мобильные клиенты, сеть и конкретный сценарий `/rift menu` пользователя.
- Реальные сундуки в мире, воронки, вагонетки, шалкеры, мешки, крафт, наковальня, creative, смерть, телепортации, смена мира, краши и рестарт.
- Реальные плагины сервера пользователя, их конфигурации, экономика, аукцион, трейды, приваты, защита регионов и гонки с ними.
- Произвольные модифицированные пакеты, потери и переупорядочивание, длительная нагрузка и сценарии дюпа игроков.

Для дальнейшего расследования нужны конкретные инструкции воспроизведения, состав плагинов и изолированная копия необходимых конфигураций/мира без паролей, токенов и личных данных. Не запускать эти destructive fixture-тесты на боевом сервере.
