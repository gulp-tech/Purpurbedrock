# Совместимость старых Bedrock-клиентов с 26.2

Работа выполняется поэтапно. Клиентам отправляются только совместимые представления; серверные сущности и предметы не заменяются и авторитетными остаются данные сервера. Внешний аддон не требуется. Версии Bedrock сопоставляются по протоколу и набору поддерживаемых функций, а не путём сравнения текстовых номеров с Java 26.2.

## Серный куб

Для Bedrock до 26.30 (протокол < 1001) реализован кандидат: вместо серного куба показывать слизня, а звуки `ABSORB_BLOCK` и `EJECT_BLOCK` заменять поддерживаемым звуком слизня. Свойства и метаданные таймера, относящиеся только к серному кубу, для такого клиента не отправляются. С 26.30 и новее эти замены не применяются. Ни серверный тип моба, ни его дроп, ни механики не меняются.

Основание: кодек 1.21.90 не содержит `ABSORB_BLOCK`; ошибка была в логе основного сервера на ядре `58174b2`. Изолированный [тест 43250080583](https://github.com/gulp-tech/Purpurbedrock/actions/runs/43250080583) использовал реальную серверную сущность и пакетные клиенты: старый JAR в положительном контроле воспроизвёл `No id found for ABSORB_BLOCK`; кандидат с 1.21.90 отправил `minecraft:slime` и три `SquishSmall` без ошибки; кандидат с 1.26.51 отправил `minecraft:sulfur_cube`, `absorb_block` и `eject_block`. Клиентский интерфейс, картинка, слышимость звука и реальные плагины требуют отдельной проверки на настоящих клиентах. Проверена только эта схема, а не все возможные звуки и мобы.

JAR собран в [43244753888](https://github.com/gulp-tech/Purpurbedrock/actions/runs/43244753888), исходный commit `de1e2255e74dea8f80a315066f05b0fa61962440`. Дополнительные синтетические проверки меню, переносов и дропа: [43250932971](https://github.com/gulp-tech/Purpurbedrock/actions/runs/43250932971); реальный сервер с пользовательскими плагинами и миром они не заменяют.

Для множества старых блоков и предметов раньше уже существовали серверные fallback-маппинги. Это не означает, что все мобы, звуки, предметы, кастомные данные и взаимодействия всех версий проверены или полностью совместимы. Глобальные переопределения обычных мобов/предметов для новых версий не вводятся.
